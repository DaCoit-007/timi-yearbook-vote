两个版本：

- **[项目沟通版（对外）](./project.html)** — 给各游戏项目同学查看。已软化口径、主打情怀，含三类道具支持说明。

- 签到 +1 张/天、同学录分享 +1 张、多游戏登录每款 +1 张（加速）
- 扭蛋机每 3 抽必出 1 件复刻情怀道具
- 18 款天美游戏参与，每款提供 1 件复刻 + 1 件 18 周年新道具 + 常规福利
- 三类道具：18 周年新道具（重开发）/ 复刻情怀道具（主福利）/ 活动福利道具
